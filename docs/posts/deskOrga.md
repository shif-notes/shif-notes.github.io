# Desktop Organization

## Strategies for clean desktops, effective file management

<!-- more -->

Got a meeting and you are stuck looking for files on your desktop?

Let's organize your desktop with these simple ways

1. Don't save files on desktop or on C: drive as you will fill up that space which would be needed to install software.
2. Save files in other drives
3. If your work involves having many files on daily basis create folders according to dates that means name your folder with today's date.
4. Create separate folders for every project you are working on and save the relevant files, you can create sub folder based on your needs.

In this way you may avoid clutter and fetch the files immediately even if it's last minute.
